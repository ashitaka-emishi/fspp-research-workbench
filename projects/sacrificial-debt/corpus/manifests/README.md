# Corpus Manifests

Corpus manifests define planned or approved source scope before canonical source
records are created.

They are not substitutes for `projects/sacrificial-debt/data/sources.jsonl`.
Every source that enters the canonical corpus still requires provenance, rights,
tier, checksum, and stable identifier records.
