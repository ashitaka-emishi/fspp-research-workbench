# Raw Sources

Raw source binaries/text are governed by redistribution status, not by capture
method.

Commit captured source material only when its rights and redistribution status
permit publication in a public GitHub repository. Public-domain, openly
licensed, or otherwise redistributable scraped/captured material may be kept in
Git when the source record documents the URL, access datetime, capture method,
local path, and checksum.

Copyrighted, restricted, rights-uncertain, or non-redistributable working copies
must stay local and gitignored. Every gitignored source still needs a provenance
record in `projects/sacrificial-debt/data/sources.jsonl` and an entry in
`projects/sacrificial-debt/corpus/provenance/GITIGNORED_SOURCES.md` explaining
where and how to reacquire the same document.
