# Sacrificial Debt Codebook — Scaffold v0.2.0

This file is a starting codebook shell. Do not expand categories because a model suggests them; record proposed changes in `DECISION_LOG.md` and version the codebook.

## Unit

The principal interpretive unit is the **proposition**. It may occupy part of a sentence, one sentence, or multiple sentences, but must resolve to exact stable source coordinates.

## Minimum debt evidence rule

Code **strong** Sacrificial Debt evidence only when all are present:

A. identifiable prior or ongoing sacrifice;  
B. explicit comparison with a less-sacrificing, spared, or benefiting actor;  
C. normative implication that the second actor therefore owes, deserves less, must contribute, or may legitimately be sanctioned.

Without C, evidence may support sacrificial asymmetry but not debt.

## Emic / etic

- **emic:** actors explicitly articulate owing/payment/balance/reciprocal obligation or close equivalent;
- **etic:** researcher reconstructs creditor/debtor logic without explicit debt language;
- never treat them as evidentially identical.

## Identification layer

Code observable structure first: collective object, sacrificer, sacrifice type, alleged survivor, explicit comparison, valuations, actor, audience, date, evidence domain.

## Interpretation layer

Only after observation lock: asymmetry/debt, creditor/debtor, reciprocal obligation, essentialization, dischargeability, sanctions, causal role, rivals, negative evidence.

## Evidence domains

`rhetoric`, `reception`, and `policy` are separate. Evidence in one domain does not automatically establish another.
